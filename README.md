## 🚀 What I'm Building

### 🤖 Local AI Infrastructure — AP0110 Systems

Architected a **5-module AI infrastructure stack** separating core services, model management, persistence, GUI, and shared components for model-agnostic local LLM workflows.

Built **Shimmy Core Service** around lifecycle control, health monitoring, automatic restart, and endpoint tracking, projecting a **~53% reduction in service-management workload**.

### 🔬 Computer Vision — BFAI Semicon Japan

Built a YOLO-based PCB defect-detection pipeline across **693 images, 2,953 annotations, and 6 defect classes**, improving performance **23% relative (0.504 → 0.620)**.

Also designed a causal-inference interface using **SHAP feature attribution** and evaluated MLOps platforms across experiment tracking, visualization, and pipeline workflows.

### 🥔 Desk Potato — CalHacks 2025

Real-time posture and eye-strain monitoring through a standard webcam, combining **Depth Anything V2, facial analysis, Letta AI, and LiveKit**.
